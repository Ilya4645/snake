Введение
========

Обзор игры
----------

"Змейка" - это классическая аркадная игра, в которой игрок управляет
змейкой, которая постоянно движется. Цель игры - собирать яблоки,
избегая столкновений со стенами и собственным телом.

Архитектура проекта
-------------------

Проект построен на принципах объектно-ориентированного программирования:

* **GameObject** - базовый класс для всех игровых объектов
* **Snake** - класс змейки, наследник GameObject
* **Apple** - класс яблока, наследник GameObject
* **GameController** - контроллер игры
* **DatabaseManager** - менеджер базы данных
